# 解説づくりのルール（愛玩動物看護師 過去問アプリ）

受験生が「間違って覚える」ことが最大のリスク。**出典の本文で裏付けが取れたことだけを書く。** 自分の記憶だけを根拠にした記述は1文たりとも書かない。裏付けが取れなければ、その問題は `skip` にする（空欄のほうが誤情報よりずっと良い）。

## 前提
- 正答は公式（一般財団法人動物看護師統一認定機構）の発表で確定している。解説は「なぜその選択肢が正しいか／他がなぜ違うか」を出典で裏付けて説明するもの。
- 出典の内容が公式正答と食い違う場合（法改正・統計の更新など）は、勝手に正答を変えず、`"conflict": "…"` に状況と出典を書く。

## 使ってよい出典（優先順）
1. **法令**：e-Gov法令検索。`python3 tools/law.py <法令名> <条番号...>` で現行条文を取得できる（例：`python3 tools/law.py 獣医師法 21`）。URLは `https://laws.e-gov.go.jp/law/<law_id>`（ツール出力の2行目）。
2. **官公庁・公的機関**（go.jp）：環境省、農林水産省、厚生労働省、消費者庁、動物医薬品検査所、国立健康危機管理研究機構（JIHS、旧 国立感染症研究所）、食品安全委員会など。
3. **試験機関**：出題基準 https://www.ccrvn.jp/aigan_shiken/shutsudaikijun.pdf
4. **信頼できる専門資料**：MSD Veterinary Manual（https://www.msdvetmanual.com/ ）、MSDマニュアル プロフェッショナル版／家庭版（日本語・人医療）、WSAVA・AAHA・ISFM・FEDIAF・AAFCO などのガイドライン、学会（日本獣医学会など）、大学（ac.jp）の公開資料、PubMed等の査読論文、日本動物看護職協会・日本愛玩動物看護師会の公開文書、ペットフード協会の飼育実態調査。

**使ってはいけない**：Wikipedia、個人ブログ、一般の動物病院のコラム、予備校・解答速報サイト、まとめサイト、AI生成と思われるサイト、出典不明のページ。

## 出典の取得方法（必須・使用量節約のため）
- **WebFetch は使わない。** 出典は必ず `python3 tools/fetch.py URL --grep 語1 語2` で取得する。本文は private/sources/ に共有保存され、他の作業役や検証役も再ダウンロードせずに使える。
- 全文を表示しない。`--grep` で必要な箇所だけ見る（`--head 3000` は冒頭確認が必要なときだけ）。
- 法令は e-Gov URL（`https://laws.e-gov.go.jp/law/<law_id>`）をそのまま fetch.py に渡せる（law_id は `python3 tools/law.py <法令名>` の出力2行目で分かる）。
- 出典探しには WebSearch を使ってよい。

## 手順（1問ずつ）
1. 問題文・選択肢・公式正答を読む。
2. 根拠になる出典を探し、**実際に本文を取得して読む**（WebFetch／WebSearch／`tools/law.py`。PDFは `curl -sL -o x.pdf URL` してから `tools/.venv/bin/python -c "import fitz;print(''.join(p.get_text() for p in fitz.open('x.pdf')))"` で読める）。
3. 本文で確認できたことだけで解説を書く。各 `refs` の `note` には、根拠にした箇所の**短い引用（原文そのまま・50字以内）**か、条・項・ページなどの位置を書く。
4. 選択肢ごとの説明（`choices`）は、裏付けが取れた選択肢だけ具体的に書く。取れない選択肢は「正答ではない」程度の事実だけにとどめるか、`choices` 自体を省く。
5. **根拠の原文を `evidence` に記録する（必須）。** 解説の各主張（summary／choices の各項目／point／lesson の各段落）について、根拠になった出典の文を**原文そのまま**（30〜150字、改変・省略記号なし）で抜き出し、`{"url": ..., "quote": ..., "for": "summary|c1〜c5|point|lesson1…"}` として並べる。検証役は `python3 tools/check_evidence.py` でこの引用が出典本文に実在するかを機械照合し、引用が主張を支えているかを確認する。evidence が無い主張は削除される。
6. 迷ったら書かない。

## 出力形式
指定された出力ファイルに、次の形のJSONオブジェクトを書く（キーは問題ID）。

```json
{
  "k1-hissu-017": {
    "summary": "正答の理由を2〜4文で。どの出典の何に基づくかがわかるように。",
    "choices": ["①の説明", "②の説明", "③の説明", "④の説明", "⑤の説明"],
    "point": "試験で覚えるべき要点を1〜2文で（任意）。",
    "lesson": ["周辺知識の段落1", "段落2"],
    "refs": [
      { "title": "出典名（法令は条番号も）", "url": "https://…", "note": "根拠箇所の短い引用 or 位置" }
    ],
    "evidence": [
      { "url": "https://…", "quote": "出典本文の原文そのまま", "for": "summary" },
      { "url": "https://…", "quote": "…", "for": "c3" }
    ],
    "checked": "2026-10-03"
  },
  "k1-hissu-020": { "skip": "裏付けとなる公開資料が見つからなかった" }
}
```

- `choices` を書くなら必ず5要素（選択肢の順番どおり）。**各項目は必ず「正答。」（公式正答の選択肢）または「正答ではありません。」（それ以外）で始める。**「誤っているのはどれか」型でも、公式正答の番号の選択肢が「正答。」。書き終えたら `python3 tools/check_answers.py <出力ファイル>` で problems: 0 を確認する。
- 書き終えたら自分で `python3 tools/check_evidence.py <出力ファイル>` を実行し、NOTFOUND / NOEVIDENCE をゼロにしてから終える。
- `lesson`（「今日のワンポイント」用の周辺知識）は、試験によく出る重要テーマの問題にだけ、2〜3段落つける（全体の2割程度）。これも出典で裏付けが取れたことだけ。
- 丸数字（①〜⑤）は選択肢番号にだけ使う。法令の号や箇条の列挙には (1)(2) などを使う。
- やさしい日本語で、受験生向けに。専門用語には必要に応じて一言の説明を添える。
- 公式の問題文・正答の出典はアプリが自動で表示するので、`refs` に入れなくてよい。
- 本文の長い引用・転載はしない（著作権）。要約して自分の言葉で書く。
